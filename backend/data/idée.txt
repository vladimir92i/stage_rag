Oui c'est une très bonne pratique — c'est ce qu'on appelle le profiling utilisateur. Par exemple :

"Bonjour ! Je suis [bénévole / partenaire entreprise / association bénéficiaire / particulier]"

Comment utiliser ce contexte :

Option 1 — Filtrer les chunks Qdrant par profil
python

# Tagger tes chunks au moment de l'indexation
payload={
    "texte": chunk,
    "profil": ["benevole", "particulier"]  # à qui ce chunk est destiné
}

# Filtrer au moment de la recherche
filter = models.Filter(
    must=[models.FieldCondition(
        key="profil",
        match=models.MatchAny(any=[profil_utilisateur])
    )]
)

Option 2 — Injecter le profil dans le prompt LLM
python

prompt = f"""
Tu es un assistant pour Les Bricos du Cœur.
Tu parles à un {profil_utilisateur}.
Adapte ta réponse en conséquence.

Contexte : {chunks}
Question : {question}
"""

Option 3 — Les deux combinées — filtrer les chunks ET adapter le ton du LLM.

Pour ton cas je te conseille l'option 2 pour commencer — c'est simple à implémenter et ça améliore déjà la qualité des réponses sans modifier ton indexation.
